# Eskiz.uz SMS integration for MakonBook

MakonBook now has a native `eskiz` SMS provider behind the existing `send_sms(phone, message)` abstraction. HolliHop synchronization code does not call Eskiz directly, so the provider can be disabled or replaced without changing the sync engine.

## 1. Current safety state

Keep SMS disabled until the Eskiz account, sender/originator, and operator-approved message template are ready:

```env
MAKONBOOK_SMS_PROVIDER=disabled
```

Nothing is sent while this value is `disabled`.

## 2. Eskiz configuration

Add secrets only to the real environment file / deployment secrets. Do not commit them:

```env
MAKONBOOK_SMS_PROVIDER=eskiz
MAKONBOOK_SMS_TIMEOUT_SECONDS=15

ESKIZ_API_BASE_URL=https://notify.eskiz.uz/api
ESKIZ_EMAIL=YOUR_ESKIZ_ACCOUNT_EMAIL
ESKIZ_PASSWORD=YOUR_ESKIZ_ACCOUNT_PASSWORD
ESKIZ_SENDER=4546
ESKIZ_CALLBACK_URL=
ESKIZ_TOKEN_CACHE_SECONDS=21600
```

The native adapter uses:

- `POST /auth/login` to obtain a bearer token;
- `POST /message/sms/send` to submit the SMS;
- Django cache for the bearer token (Redis in production in this project);
- one automatic re-authentication attempt when Eskiz returns HTTP 401.

Passwords/tokens are never copied into MakonBook delivery logs or safe error messages.

## 3. Sender and SMS template

`ESKIZ_SENDER=4546` matches the standard sender documented by Eskiz. Replace `4546` only when your Eskiz account has an approved nickname/originator (for example, a future `MakonBook` sender). Do not assume that a custom nickname is usable before approval.

The current HolliHop credential SMS generated by MakonBook is structurally:

```text
MakonBook
Login: <login>
Temporary password: <temporary password>
https://makonbook.uz/login/
```

Submit the matching service-message template to Eskiz/operator moderation before turning on credential SMS. If the approved text differs, update the MakonBook template before production sending; changing arbitrary wording after approval can cause provider/operator rejection.

## 4. Configuration check — sends nothing

```bash
python manage.py check_sms_provider
```

A successful result means required settings are present. It does not authenticate to Eskiz and does not send SMS.

## 5. Explicit live test

Only after sender/template approval:

```bash
python manage.py check_sms_provider --send-to "+998901234567"

# Or, after your own template is approved:
python manage.py check_sms_provider --send-to "+998901234567" --message "YOUR APPROVED TEST TEXT"
```

The default test text is `This is test from Eskiz`, one of the test-mode texts currently documented for Eskiz. This makes one real Eskiz API send request.

## 6. HolliHop credential delivery

The existing flow remains explicit:

```bash
python manage.py sync_hollihop --pilot-student-id 236 --send-credentials
```

or, after pilot verification:

```bash
python manage.py sync_hollihop --all --send-credentials
```

Rules already enforced by the project:

- credentials are sent only for MakonBook users actually created from HolliHop;
- inactive students do not receive credentials;
- a successful delivery is not silently resent by later synchronization;
- a failed/partial delivery requires the Manager reset-and-resend action;
- the plaintext temporary password exists only during delivery and is never stored in the delivery model/log.

## 7. Production checklist

1. Create/verify the Eskiz account.
2. Confirm the sender/originator that Eskiz allows for the account.
3. Approve the exact MakonBook service SMS template with Eskiz/operators.
4. Put `ESKIZ_EMAIL`, `ESKIZ_PASSWORD`, and `ESKIZ_SENDER` into deployment secrets.
5. Keep `MAKONBOOK_SMS_PROVIDER=disabled` while the Eskiz account/template is still being prepared.
6. When the account is ready, set `MAKONBOOK_SMS_PROVIDER=eskiz` and add the Eskiz secrets.
7. Run `python manage.py check_sms_provider` (this check itself sends nothing), then restart web/Celery services.
8. Send one intentional test SMS with `--send-to`.
9. Test one HolliHop pilot account with `--send-credentials`.
10. Only then enable bulk credential delivery.
