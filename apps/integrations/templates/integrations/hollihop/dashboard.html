Sync strategy

Built around Hollihop's 600 requests / 30 sec limit and their warning about GetEdUnitStudents.
Every {{ sync_interval_minutes }} minStudent delta + EdUnit delta. Only changed rows are fetched where Hollihop supports lastUpdatedFrom.
Every {{ teacher_poll_minutes }} minTeacher list check. Existing MakonBook teachers are updated only when fields/role state changed.
Every {{ membership_sweep_minutes }} minRelation-only membership safety sweep. No Days/payments. Historical/ended EdUnits are ignored and unknown classrooms are created only when a current student actually belongs to them.
Every {{ student_profile_sweep_minutes }} / {{ edunit_catalog_sweep_minutes }} minLow-frequency student profile / EdUnit catalog safety checks for changes Hollihop cannot signal incrementally.
Membership limitation: Hollihop confirmed that adding/removing a student from an EdUnit does not update EdUnit.lastUpdated. That is why a low-frequency relation sweep is still necessary; doing a full GetEdUnitStudents export every 5 minutes would be the wrong implementation.
